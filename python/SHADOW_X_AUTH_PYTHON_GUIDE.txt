HOW TO INTEGRATE SHADOW X AUTH IN YOUR PYTHON APPLICATION:

STEP 1: Copy `shadowxauth.py` into your Python project directory.
STEP 2: Import and initialize in your script:

   from shadowxauth import ShadowXAuth

   auth = ShadowXAuth(
       app_owner_id="YOUR_APP_OWNER_ID",
       app_secret="YOUR_APP_SECRET",
       version="1.0"
   )

   license_key = input("Enter License Key: ")
   result = auth.validate_license(license_key)

   if result.get("success"):
       print(f"[+] Access Granted! Welcome {result.get('username')}")
   else:
       print(f"[-] Access Denied: {result.get('message')}")
